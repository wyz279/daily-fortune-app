# daily-fortune-app
## 【今日靈籤占卜】網頁規格說明書
### 一、 基本資訊與外觀風格（Basic Info & UI）
檔案格式：單一 index.html 檔案（內含 HTML、CSS 樣式與 JavaScript 互動邏輯），不需架設後端伺服器，雙擊即可開啟或直接部署至 GitHub Pages。
整體畫風與美學風格（獨立樂團／潮流專輯美學）：
風格定調：融合「當代獨立搖滾與潮流另類專輯封面」的視覺美學。整體呈現帶有個性、俐落、冷調卻不失溫度的現代文青感（充滿設計感與藝術張力）。
色彩規範：
背景色：沉穩且具有神祕感的深灰黑色或深夜靛藍色（例如 #121212 或 #0d1117）。
主色調與點綴色：採用高對比或低彩度的潮流色調（如工業灰、低調的霧面霓虹紫、冷光藍、或是帶有實驗性質的螢光/金屬質感點綴）。
文字顏色：高辨識度的純白色或淺米灰，排版常伴隨粗體、不對稱留白或極具現代感的字體粗細對比。
視覺細節與特效：
UI 元件（如籤筒、卡牌、結果彈窗）保持俐落的幾何邊框或微圓角，搭配強烈的明暗對比陰影（Drop Shadow）或外框線條（Border Glow），營造出類似實體專輯包裝的質感。
動畫效果要滑順且帶有節奏感（使用 CSS transition 與 transform），不管是籤筒的快速晃動還是抽開時的滑動特效，都要流暢不卡頓。
響應式設計（RWD）：完美適應電腦螢幕與手機版面，確保在各種螢幕尺寸下都能維持極佳的視覺排版與點擊體驗。
### 二、 畫面與互動流程（Interactive Workflow）
進入畫面（首頁狀態）：
畫面上方顯示簡潔有力的標題（例如：「TODAY'S FORTUNE / 今日靈籤」）。
中央呈現一個設計感十足的籤筒，並附上提示文字：「請長按籤筒進行洗籤，放開即可停止並抽籤」。
長按洗籤互動（核心特色）：
使用者按住滑鼠左鍵（或手機長按）不放時，畫面上的籤筒或籤隻開始快速晃動、洗牌，並伴隨微幅震動與視覺特效。
當使用者放開按鈕的瞬間，洗籤動畫停止，畫面展開多支籤供使用者選擇。
使用者點擊其中一支籤後，該支籤移動到畫面中間放大，其他籤消失，並伴隨開牌特效。
選籤與結果揭曉（雙資料庫獨立抽樣）：
系統在背景從「運勢與說明資料庫」隨機抽出一筆，並同時從「幸運色資料庫」隨機抽出一筆，將兩者動態組合成當日的專屬籤詩結果。
畫面展示最終結果，包含：
運勢等級與專屬說明（例如：大吉、上上籤、突破現狀等正向運勢，搭配一段富有哲理或現代感的解籤說明）。
今日幸運色（以具有設計感的色票方塊或背景裝飾呈現，並附上色彩名稱）。
提供「再抽一次」按鈕，可隨時回到初始畫面重新長按抽籤。
### 三、 程式技術與實作細節（Tech Details for AI）
事件監聽（Event Listeners）：使用 JavaScript 的 mousedown / mouseup（電腦版）與 touchstart / touchend（手機版），精準抓取使用者的「長按」與「放開」動作。
多資料庫架構（Multiple Datasets）：
資料庫 A（運勢與說明）：內含多筆包含「運勢等級」與「對應籤詩說明」物件的陣列。
資料庫 B（幸運色）：內含多筆包含「顏色名稱」與「HEX 色碼」物件的陣列。
組合邏輯：當觸發抽籤時，分別從兩座資料庫中各自獨立 Math.random() 隨機抽出一筆資料，並渲染到畫面上。
### 四、 網頁預期成功標準（Success Criteria）
網頁為單一 index.html 檔案，可在瀏覽器流暢運作。
「長按洗籤、放開選籤」的互動邏輯順暢，動畫流暢。
能夠成功從兩個獨立資料庫隨機抽取並組合成最終結果，介面風格符合現代潮流獨立音樂專輯般的質感與美學。
